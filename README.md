One word, first thought. The entry is a single word — the first that comes
to mind, no topic, no explanation, no second draft — written by `main.py`
to `/output/entry.txt`.

The word is **zugzwang**: chess for a position where any move you make
worsens your situation. Nobody guesses a German chess term as a first
thought; the trapped feeling is instantly felt, not just pictured; and
the word doubles as a whole philosophy of bad days — every option makes
it worse.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
